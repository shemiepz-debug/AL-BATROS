# Al-Batros Accounts — GitHub Actions APK Build

## How to Build the APK on GitHub (Zero Local Setup Needed)
1. Create a new repository on **GitHub** (e.g., `al-batros-accounts`).
2. Extract this ZIP and upload **all files and folders** (including `.github/workflows/build-apk.yml`, `package.json`, `capacitor.config.json`, and `www/index.html`) to the root of your GitHub repository.
3. Open the **Actions** tab in your GitHub repository.
4. Click **Build Al-Batros Accounts Android APK** (or wait for the automatic run triggered by your upload/push to finish).
5. Once the workflow shows a green checkmark, scroll down to **Artifacts** and download **`Al-Batros-Accounts-APK`** (`app-debug.apk`).
6. Install `app-debug.apk` directly on your Android phone or tablet.
